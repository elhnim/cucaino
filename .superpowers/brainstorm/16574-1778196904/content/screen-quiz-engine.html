2
Question draw — how each mode pulls questions
🎯
Solo
1. Build pool for kid's age band
2. Shuffle → draw N questions (quiz set count)
3. Serve one at a time, no repeats
4. End after N questions
🔄
Taking Turns
1. Build one pool per player, each filtered to their age band
2. Each turn: draw 1 question from that player's pool
3. Remove drawn question — no repeats per player
4. Rotate players: P1 → P2 → P3 → P1…
5. End after N total questions (shared count)
📱
Multiplayer
1. Build one pool per player, age-matched
2. Each round: host draws 1 question per player from their pool simultaneously
3. Each device shows its player's own question — same theme, age-matched difficulty
4. All timers start together (broadcast event)
5. N rounds (not N questions per player)
3
Scoring formula — speed-based, all modes
Formula
points = round(
  MIN_PTS +
  (MAX_PTS − MIN_PTS) ×
  (1 − answerTime / TIME_LIMIT)
)
MAX_PTS = 1000
MIN_PTS = 100
TIME_LIMIT = 20 seconds
Wrong / no answer = 0 pts

⏱ Timer rules
· Time limit = 20 seconds per question
· Timer starts the moment the question is shown (not when the player reads it)
· Timer stops the instant the player taps an answer
· Shown as a circular countdown ring on-screen
· Ring turns red in the last 5 seconds
· If timer reaches 0 before answering → treated as wrong (0 pts)
📊 Score display in session
· After correct: +920 pts · 1.8s · 3,740 total
· After wrong / timeout: "Not quite!" · 0 pts · 3,740 total
· Running total always visible in session header
· Between-round leaderboard (Multiplayer) shows rank + total points
Fill in the Blank — timing
Timer starts when question is shown. Player types and hits Submit. Answer time = moment of Submit tap, not the last keystroke. Case-insensitive, whitespace-trimmed. Accepted variants checked.
4
Multiplayer sync — event flow (Supabase Realtime)
Who broadcasts
🟢 Host (Liam's device)
🔵 Server (Supabase)
🟡 All players
Host
session_create
Creates room in DB → gets 4-digit code. Pre-draws all question pools server-side.
Players
player_join
Each player enters code → subscribes to room channel. Host sees them appear in lobby.
Host
round_start { roundNumber, startsAt }
Broadcast to all. startsAt = UTC timestamp 3s from now. Each device shows countdown: "3… 2… 1…" then reveals their own age-matched question simultaneously.
Players
answer_submit { playerId, answerIndex, answeredAt }
Sent to server the instant the player taps. Device immediately locks (no change). answeredAt is the client timestamp used for scoring.
Server
round_end { answers[], scores[], leaderboard[] }
Fires when timer expires OR all players have answered. Calculates points server-side (tamper-proof). Broadcasts correct answer + updated leaderboard to all devices.
Host
round_start (next round) or session_end
Host taps "Next round" → repeat. After last round, host taps "End game" → server broadcasts session_end with final leaderboard to all devices.
📡 Implementation: Supabase Realtime (Broadcast)
Channel per session: quiz-session:{roomCode}. All events use channel.send() / channel.on('broadcast'). Scoring computed server-side via a Supabase Edge Function to prevent client-side manipulation. Question pools pre-computed and stored in quiz_sessions table at session creation — not drawn on the fly during play.
