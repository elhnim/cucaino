Gamification System — Goals First

5 goals → 5 pillars. Each pillar serves a specific motivation. Together they create the loop.

What each pillar achieves
⭐
Stars — Currency
Earned per task, spent on rewards. The engine behind real rewards.
EARN REAL REWARDS
🔥
Streak — Consistency
Consecutive days all required tasks done. Milestone bonuses. Holiday mode pauses without breaking.
BUILD HABITS
🏅
Level — Identity
Based on total stars ever earned. 5 named levels with a badge shown on avatar. Never goes down.
STATUS + IDENTITY
🎖️
Badges — Achievements
One-time unlocks for milestones. Visible as a collection. Each unlock triggers a celebration.
MOTIVATE + STATUS
🏆
Family Board — Competition
Weekly sibling leaderboard — stars earned this week, streak, tasks done. Resets every Monday.
